# 🌸 Flower Image Classification

## Project Overview
This beginner-level Python project explores flower image collection, preprocessing, and visualization using Google Colab.

## Flower Categories
- Roses
- Sunflowers
- Tulips
- Daisies

## Tools and Libraries
- Python
- PIL (Pillow)
- NumPy
- Matplotlib
- Google Colab
- Google Drive

## Data Preprocessing
- Load images from Google Drive.
- Convert images to RGB format.
- Resize images to 128 × 128 pixels.
- Normalize pixel values from 0–255 to 0–1 using NumPy.
- Visualize sample images.

## Project Status
Image collection and preprocessing workflow for a beginner-level image classification project. A trained classification model and its accuracy have not yet been verified.

## Learning Objectives
- Practice Python classes and functions.
- Work with image data using PIL.
- Use NumPy for array operations.
- Learn basic image preprocessing and visualization.
